# 보고 일정 보드 (로컬 실행판)

부서장 보고 일정 관리 도구 PRD v1.0의 MVP입니다. 별도 설치 없이 Windows 기본 PowerShell로 실행됩니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `start.bat` | 더블클릭하면 서버를 켜고 브라우저를 엽니다 |
| `server.ps1` | 로컬 웹 서버 + 데이터 저장 API |
| `public/index.html` | 웹앱 화면 (보고 접수 / 일정 확정) |
| `data/` | 저장된 데이터 (처음 실행할 때 생김). 보고 건과 고정 일정이 건마다 JSON 파일로 저장됩니다 |

## 실행 방법

1. 이 폴더를 서버로 쓸 PC(보통 일정담당 PC)에 둡니다.
2. `start.bat`을 더블클릭합니다.
   - 검은 창이 뜨고 브라우저가 `http://localhost:8080`으로 열립니다.
   - **검은 창을 닫으면 서버가 꺼집니다.** 쓰는 동안에는 창을 켜 두세요.
3. 끝낼 때는 검은 창을 닫거나 `Ctrl+C`를 누릅니다.

8080 포트를 다른 프로그램이 쓰고 있으면 명령 프롬프트에서 다른 포트로 실행합니다.

```bat
start.bat 8081
```

## 부서장 PC에서 같이 보기

1. 서버 PC의 검은 창에 나온 `Other PCs: http://192.168.x.x:8080` 주소를 확인합니다.
2. 부서장 PC 브라우저에서 그 주소를 엽니다. 두 PC가 같은 사내망에 있어야 합니다.
3. 처음 실행할 때 Windows 방화벽 허용 창이 뜨면 **개인/회사 네트워크 허용**을 누릅니다.
   - 창이 뜨지 않았는데 접속이 안 되면, 서버 PC 관리자가 방화벽에서 TCP 8080 인바운드를 허용해야 합니다. 회사 보안 정책상 막혀 있을 수 있으니 전산 담당자에게 확인하세요.
4. 각자 화면 위쪽 **역할**에서 「부서장」 또는 「일정담당」을 고릅니다. 선택은 그 PC에 기억됩니다.

상대방이 바꾼 내용은 **새로고침** 버튼을 누르거나, 브라우저 창을 다시 클릭하면 반영됩니다.

## 사용 흐름

1. **보고 접수** 화면: 일정담당이 낮 동안 받은 보고 건(대면/비대면, 소요 10·20·30분)과 위원회 등 고정 일정을 입력합니다.
2. **일정 확정** 화면 (기본: 내일)
   - 일정담당: 대면 보고를 시간표로 끌어다 놓거나 시간을 골라 「배치」합니다. 위원회·점심·다른 보고와 겹치거나 근무시간을 벗어나면 경고가 뜹니다. 참고 보고는 「결재판으로 이동」합니다.
   - 부서장: 배치된 보고를 「확정」 또는 「변경 요청」(사유는 비고에 기록)하고, 결재판 보고에 「확인 완료」를 체크합니다.
   - 위쪽에 대면 건수·총 시간, 비대면 건수, 개인 업무 가능 시간(480 − 고정 일정 − 대면 보고)이 표시됩니다.
3. 당일 급한 보고는 날짜를 「오늘」로 바꿔 같은 방식으로 추가합니다.

## 백업

`data` 폴더를 통째로 복사하면 백업됩니다. 되돌릴 때는 서버를 끄고 `data` 폴더를 바꿔 넣은 뒤 다시 켭니다.

## 주의

- 로그인이 없습니다. 서버 주소를 아는 사내망 사용자는 누구나 열 수 있으니, PRD 10장 운영 규칙대로 업무명은 약칭, 보고자는 부서명 위주로 입력하세요. 출시 전 조직 보안 규정 확인이 필요합니다.
- 같은 보고 건을 두 사람이 동시에 고치면 나중에 저장한 내용이 남습니다.
- 글꼴은 인터넷이 되면 IBM Plex Sans KR을 쓰고, 안 되면 맑은 고딕으로 표시됩니다.
